As sugestões desta versão vêm de uma base editorial inspirada no Guia Alimentar para a População Brasileira. Não fazemos pesquisa automática na internet nem usamos seus dados para treinar uma IA.

O guia substitui uma consulta?+

Não. Ele organiza ideias de alimentação e hábitos. Quantidades, calorias, suplementação e tratamento nutricional dependem de avaliação individual com nutricionista.

O que vem no meu PDF?+

Seu resumo, sugestões para um dia, trocas de alimentos, uma opção doce, estratégias para sua dificuldade e a fonte consultada. Para perfis que precisam de cuidado individual, o PDF traz o resumo para levar à consulta.

Meus dados são armazenados?+

Não há banco de dados nesta versão. Seu perfil fica temporariamente na memória da página. O PDF baixado fica no seu dispositivo; compartilhe apenas se desejar.
